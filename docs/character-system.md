# 角色與裝備系統（交接文件）

視覺參考：`docs/character-design.html`（瀏覽器開啟即可看動畫，`drawGear()` 是畫法的權威來源）。

## 已決定
- 畫風：**中性灰身體＋貼紙描邊＋酷炫版**（深色舞台、稀有度彩色外框與光暈、倒三角體型、專注眼神）。
- 不用圖檔，全部 SwiftUI `Canvas` 依「關節座標」即時畫；動作 = 兩組關節在起點/終點之間內插。
- 裝備：12 個系列 × 8 部位（頭部、上衣、下身、鞋子、手部、背部、啞鈴造型、特效）。
  英雄類系列（鈦甲、夜巡者、曙光、符文戰神、星界魔導）是**原創**，不得做成漫威／DC／英雄聯盟的角色或造型。
- 機制採用 1、3、4、5（2「每月新系列」不做，12 系列一開始就全部可抽）：
  1. **補給箱**：每完成一次訓練 = 1 箱（由 `WorkoutSession` 數量推算，不改訓練流程）。
     機率 普通 60／稀有 28／史詩 10／傳說 2；連續 9 箱沒出史詩以上，第 10 箱保證史詩以上。
  3. **實力裝備**：黃金系列 8 件只能靠里程碑拿，補給箱不會掉。
  4. **套裝效果**：同系列裝備 4 件以上 → 光環換系列色、戰力 ×1.2。
  5. **碎片**：抽到已擁有的 → 碎片（普通 5／稀有 10／史詩 25／傳說 60）；碎片兌換（20／50／120／300），黃金系列不可兌換。
- 基本款全套一開始就送。

## 黃金系列里程碑
| 裝備 | 條件 |
|---|---|
| 特效・金光 | 累積 10 次訓練 |
| 下身・黃金短褲 | 累積 25 次訓練 |
| 上衣・黃金背心 | 累積 50 次訓練 |
| 頭部・王者之冠 | 累積 100 次訓練 |
| 鞋子・黃金戰靴 | 連續 4 週達標（`Stats.weekStreak`） |
| 背部・王者披風 | 連續 8 週達標 |
| 手部・黃金拳套 | 破個人紀錄 10 次 |
| 啞鈴・純金啞鈴 | 破個人紀錄 30 次 |

破個人紀錄：某個有負重的動作，某組重量大於該動作之前所有紀錄的最大重量（第一次做不算）。

## 程式位置
- `Workout/Character/`：骨架與動作、裝備目錄、Canvas 繪製、背包狀態、角色分頁、開箱畫面、碎片兌換。
- 背包存在 `UserDefaults`（JSON 字串），key 前綴 `workout.character.`；不動 SwiftData 模型。
- 分頁：今天、角色、進步、行程、設定；「紀錄」移到「進步」右上角按鈕（sheet）。
