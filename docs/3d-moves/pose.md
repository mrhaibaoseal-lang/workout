# 動作卡：姿勢批次（`scripts/blender/moves/pose.py`）

負責：Claude（動作）。這批是**不在動作庫的展示姿勢**（分享卡等畫面用），不是訓練動作，不加進 `Hero3DExerciseMap.byExercise`。
節奏：48 格一循環，第 47 格和第 0 格連得起來（cos 波）。角度範圍同時寫在 `pose.py` 檔頭 `MOVE_META` 的 `angles`。
不拿啞鈴（`bell` 不開）、背部裝備照常顯示（`lean_back` 不開）。

## 單手秀二頭 `flex`
- 用途：分享卡的角色姿勢（使用者決定改用 3D、姿勢是單手秀二頭）。分享卡只取**第 24 格**（中間），那格是最用力、姿勢最完整的時候。
- 姿勢：雙腳比髖略寬、膝蓋微彎（不鎖死）、挺胸站直。
  - **左手秀二頭**（角色左邊＝Blender x 為正）：上臂往側邊抬到約水平（略往前 12°、略高於水平 5～9°）、手肘約 76～88°、握拳，拳頭往頭的方向收，二頭肌（上臂前側）朝前。
  - **右手扠腰**：拳頭靠在髖骨上緣外側、手肘朝外（同 `rest.py` 的叉腰）。
- 為什麼是左手：App 鏡頭（`Hero3DStage.swift` 的 `yaw = -0.5`）把角色往右轉，鏡頭在角色的**左前方**約 29°。
  左手在靠鏡頭那一側，整條手臂和二頭肌都在身體前面、不會被擋；右手秀的話上臂會被軀幹和頭擋掉一半，扠腰的手在遠側也比較不搶畫面。
- 循環：t＝0.5−0.5·cos(2π·f/48)。t 越大越用力：手肘再彎 12°、上臂再抬 4°、胸口略挺（上身後仰 ≤ 3°）、膝蓋略伸直把人頂高 0.6 cm、扠腰手肘略往外。
- 關鍵角度：膝角 160～180°、左手肘 70～105°、左上臂離垂直 75～110°（約水平）、右手肘 55～125°（扠腰，公仔手臂短，同 `breathe`）、軀幹前傾（含後仰）0～8°。
- 鏡頭：`CAM` 設成 App 的鏡頭換算到 Blender（`loc=(2.205, -4.037, 1.2)`、看 `(0, 0, 0.8)`、焦距 67.2 mm＝垂直 FOV 30°），預覽圖和 App 同角度。
- 來源：展示姿勢，不是訓練動作，沒有引用動作來源；不模仿任何比賽或遊戲的商標姿勢。
- 風險：無（站姿、不負重）。
