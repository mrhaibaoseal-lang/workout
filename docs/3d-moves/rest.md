# 動作卡：休息頁批次（`scripts/blender/moves/rest.py`、器材 `props_rest.py`）

負責：Claude（動作）。三個動作：`breathe`、`drink`、`ready`。這是**組間休息畫面的待機動畫**，不是訓練動作：要循環播放、頭尾接得起來，幅度小、自然。
節奏：48 格一循環（12 fps 預覽＝4 秒）。第 47 格和第 0 格連得起來（`profile` 末尾停在起點姿勢）。
角度範圍同時寫在 `rest.py` 檔頭 `MOVE_META` 的 `angles`（`clipbatch.py` 判定），**範圍照本卡，不照量到的值**。
三個動作都不拿啞鈴（`bell` 不開）；`drink` 的水壺是 `props_rest.py` 的器材。

## 與 2D 版的差別（請主對話確認）
`CharacterPose.swift` 的 2D `breathe` 是「彎腰、雙手扶膝喘氣」。本批照主對話的指示做**站姿深呼吸、雙手叉腰**（見下），沒有彎腰。
理由：站姿叉腰是組間恢復最常見、最安全的姿勢（胸腔打開、腰椎不負重），而且和 `ready`、`drink` 起點是同一個站姿，三個畫面切換不會跳。
若主對話要和 2D 一致（扶膝），只改 `rest.py` 的 `breathe` 即可。

## 1. 深呼吸 `breathe`
- 姿勢：雙腳與髖同寬、膝蓋微彎（約 170°，不鎖死），上身直立，**雙手叉腰**（手掌貼在髖骨上緣，手肘朝外）。頭中立，眼睛看前方。
- 吸氣（約 1.7 秒，20 格）：胸腔往上撐開，上身略往後挺（胸骨頭離垂直 ≤ 8°）、肩膀不聳、手肘微微往外，頭略抬；頂端停 5 格。
- 吐氣（約 1.8 秒，21 格）：胸口放鬆、肩膀下沉、上身略往前鬆（≤ 8°），頭微低，回到起點停 2 格。
- 關鍵角度：膝角 160～180°、手肘 55～125°（叉腰；量到約 61～73°，公仔手臂短，叉腰時手肘比真人彎，原本寫的 80° 起跳，量過後放寬）、軀幹前傾（含後仰）0～9°。
- 常見錯誤（要避免）：聳肩吸氣（把肩膀抬到耳朵）、彎腰駝背、膝蓋鎖死、用嘴巴大口喘而上半身劇烈晃動。
- **App 提示**：「用鼻子吸 4 秒、嘴巴慢慢吐 6 秒，讓肚子和胸口一起鼓起來；肩膀放鬆不要聳，雙手叉腰、挺胸站直，心跳慢下來再做下一組。」
  （3D 看不出：吸氣時橫膈膜下沉、腹部擴張，肩膀不要往上抬。）
- 來源：**沒有找到「同一個變化式」的權威來源**（站姿叉腰深呼吸恢復）。目前只有組間休息時間的來源，支持「要休息、要恢復」，不支持具體姿勢：
  1. NSCA, How to Manipulate Rest Intervals to Maximize Strength Training Effectiveness（組間休息 2～5 分鐘，依疲勞調整）：https://www.nsca.com/education/articles/ptq/manipulate-rest-intervals-to-maximize-strength-training/
  2. NASM, Determining best rest periods（耐力 0～90 秒、最大肌力 3～5 分鐘）：https://blog.nasm.org/uncategorized/determining-best-rest-periods-resistance-exercise-training-goals
  - 差在：以上兩篇講**休息多久**，沒講**怎麼站、怎麼呼吸**；姿勢是依一般恢復站姿設計的。
- 來源分歧：無（沒有可比的）。取保守的：不彎腰、不憋氣、不做過大的胸腔動作。
- 風險：一般（低）。

## 2. 喝水 `drink`
- 姿勢：站姿（同 `breathe`），**右手拿水壺**，左手叉腰（或自然垂在身側）。
- 起點：右手拿水壺在腰前（手肘約 90°，壺身直立、瓶蓋朝上）。
- 舉起（約 1.2 秒，14 格）：手肘彎起把水壺送到嘴邊，水壺隨手腕傾斜（瓶蓋朝嘴）；**頭只微微後仰（≤ 15°）**、不往後折脖子。
- 喝（約 1.3 秒，16 格）：水壺傾斜約 100～120°（瓶底朝上）、停在嘴前，喉嚨微微上揚；
- 放下（約 1.5 秒，18 格）：手回到腰前，頭回中立。
- 關鍵角度：右手肘 min 60～90°（舉到嘴邊）、max 100～130°（腰前）；左手肘（叉腰）55～125°；軀幹前傾 0～8°；膝角 160～180°。
  （原本寫 min 35～75°：公仔手臂比壺短，壺有 19 cm，手腕伸到嘴前的距離讓手肘最多彎到約 80°，再彎會讓壺貼臉；量過後放寬，視覺上仍是自然的喝水動作。）
- 常見錯誤（要避免）：頭往後仰很多（頸椎過度伸展）、彎腰喝、壺身壓在嘴上、一口氣灌（要小口）。
- **App 提示**：「小口小口喝，每次 3～8 口（約 100～200 毫升），不要一口氣灌完；站直、頭微仰就好，不要往後折脖子。」
  （3D 看不出：每次喝的量、水溫、運動後補水速度。）
- 來源（同一個變化式：訓練中補水）：
  1. ACSM Position Stand, Exercise and Fluid Replacement（早點喝、固定間隔、容器要方便大量飲用）：https://pubmed.ncbi.nlm.nih.gov/17277604/
  2. ACSM 補水手冊（消費者版）：運動中每 15～20 分鐘喝 3～8 液盎司（約 90～240 毫升），低於 60 分鐘用水就好：https://kennesaw.edu/employee-wellness/docs/acsm-hydration-for-fitness.pdf
  - 差在：兩者講補水**量與間隔**，沒講**喝水的動作姿勢**；姿勢（頭微仰、單手握壺）是依一般喝水動作設計的。**ACE 的頁面沒有找到**。
- 來源分歧：間隔 15～20 分鐘（手冊）vs 提早規律喝（立場文件，未寫數字）。取「小口、規律」。
- 風險：一般（低）。

## 3. 準備 `ready`
- 姿勢：運動員預備姿勢（athletic stance）：雙腳與髖到肩同寬、**膝蓋微彎約 150～160°**、髖微往後坐、上身自然前傾 10～15°、胸挺起、頭抬起看前方；
  **雙手握拳舉在胸前**（手肘約 90～100°，拳在下巴到胸口之間）。
- 循環：小幅度彈跳（48 格＝3 次，每次 16 格約 1.3 秒）：髖上下約 3 cm、兩拳跟著小幅度上下，重心略往前腳掌；像在暖機等待下一組，**不是**真的跳起來，雙腳全程貼地。
- 關鍵角度：膝角 145～175°、手肘 75～115°、軀幹前傾 5～18°。
- 常見錯誤（要避免）：圓背、膝蓋內夾、腳跟離地彈跳、拳舉太高聳肩、整個人晃動。
- **App 提示**：「站穩、膝蓋微彎，背挺直、眼睛看前方，把呼吸調勻；下一組開始前先在心裡數一遍動作重點。」
  （3D 看不出：核心收緊、重心在腳掌中間。）
- 來源（同一個變化式：運動員預備姿勢）：
  1. NSCA, The ABCs of Long-Term Athletic Development（athletic position：雙腳與髖到肩同寬、約四分之一蹲）：https://www.nsca.com/education/articles/nsca-coach/abc-of-long-term-athletic-development/
  2. Medium, The Universal Athletic Position（膝微彎、髖微後坐、約四分之一蹲）：https://medium.com/performance-course/the-universal-athletic-position-33257d53b4ca
  - 差在：來源是**靜態預備姿勢**，沒有「小彈跳」；彈跳是主對話要求的「有活力的小動作」，幅度故意壓小。第二個來源不是機構來源（Medium 文章），也可再補。
- 來源分歧：腳的寬度「髖寬」vs「肩寬」；Doctor Yessis 說膝蓋只該微彎（重心高）、NSCA 說約四分之一蹲。取保守的**髖寬、膝角 150～160°**（比四分之一蹲淺）。
- 風險：一般（低）。

沉入地板：全部 0。基本款只剩大腿內側 2～3 對，叉腰的手和大腿硬碰撞已調到 0（叉腰位置上移、往外：手腕在髖中心上方 21 cm、左右 23.5 cm）。
系列裝備穿模依使用者 2026-11-24 決定只記錄、不改；**鈦甲胸甲 × 前臂（舉拳、喝水）留給裝備端**。

`deformcheck.py`（基本款，每 2 格）單格最多壞面：`breathe` 324、`drink` 348、`ready` 377。
全部集中在手肘窩（上臂＋前臂擠扁／法線翻轉／皮膚自穿，第 0 格最明顯，手肘彎約 60～90°）和肩膀（上臂＋鎖骨 ≤ 38 面）；沒有髖、腰、胸、膝的壞面。
和已完成動作（pulldown 550、skullCrusher 718）同量級，是骨架權重的手肘窩／肩膀擠壓，不是這批姿勢；目標 0 沒有達成。

**自我審查發現並修掉的問題**（發現 → 原因 → 修法）：
- 叉腰時拳頭和大腿硬碰（每格 62 對 × 2）→ 拳頭放在大腿頂端上面 → 手腕上移 6 cm、外移 2 cm、手指改往下往內：剩 0。
- `ready` 膝蓋太彎（最小 140°）、拳頭離胸太近（手肘 56°）→ 髖高和手腕位置參數偏小 → 髖高 +1.4 cm、手腕前移到 0.30 m：膝 147°、手肘 79°。
- `ready` 的「髖往後坐」做不到 → 共用的 `stand_legs` 腳踝跟著髖一起後移 → 這批自己寫腿（`_rs_stand`，腳踝釘在 y＝0.01、只移髖）。
- `drink` 壺的位置：用 `hand` 骨頭量握拳中心和握把軸（`rest_grip_frame`，同 `cable.py` 的 `hand_grip_frame`），蓋子端第 0 格選「朝上」那端、之後固定，沒有翻面。

**已知限制／請審查確認**
- `breathe` 動作幅度小（吸氣上身後仰約 4°、整個人升 1.2 cm，比我想像的不明顯）；是刻意的（待機畫面），要更明顯可以把 `rest.py` 的振幅加大。公仔沒有胸腔變形，用「身體微挺、頭微抬、手肘外開」表現。
- `breathe` 站姿叉腰，和 2D 版（彎腰扶膝）不同，見上面「與 2D 版的差別」。
- `drink` 壺傾斜只到約 60～70° 就停在嘴前（看起來是「壺口碰嘴」，不是瓶底全朝上）；再傾斜壺會戳到臉或手肘拉太彎。
- `ready` 彈跳幅度小（髖上下約 2.4 cm，兩拳左右差 1/4 拍）；要更有活力可加大。
- 水壺只有 `drink` 用，沒有系列裝備（`bell` 部位不適用）；`props_rest.py` 的 `build_bottle` 每次都載入，但只在 `drink` 時才建物件。
- 沒做 §8-1 獨立審查（主對話另外安排）。來源：`breathe` 沒有同一個變化式的來源；`drink` 的來源講量不講姿勢；`ready` 第二個來源不是機構來源（見各動作的「來源」）。
