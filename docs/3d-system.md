# 3D 角色、裝備、動作示範（正式版計畫）

最後更新：2026-11-22。原型在 `scripts/blender/`（說明見該資料夾 README），預覽在 `docs/art/blender/`。

## 使用者已決定
- 3D 用 **Blender 程序化建模**（Python 腳本產生，不手工雕刻），風格＝目前原型：卡通兩階著色＋黑描邊＋邊緣光、玩具公仔比例。
- **App 內即時 3D**（不是預先算好的影片）：示範動作時穿著自己目前的裝備；手機 iPhone 16 Plus 效能夠。
- **示範影片不放裝備特效**（fx 部位），避免干擾看動作；特效留給角色頁。
- 初始造型：品牌橘貼身背心、深藍灰短褲、白鞋橘鞋底、深藍灰頭帶護腕；臉只有眼睛眉毛（蛋形頭，不加下巴零件）。
- 動作要準確、專業：手腳釘在地板／器材上，用 IK 解手肘膝蓋；器材照使用者自己的（見下）。
- 使用者的「多功能啞鈴椅＋高位下拉架」一體機已建模（`moves3d.py` 的 `build_bench`）：
  前端立柱＋頂部滑輪盒；**配重是立柱滑套上的兩顆啞鈴**，拉下時整組往上滑；可調靠背、頭枕、前端腳踝滾筒。

## 要做的量
- 動作：`CharacterMove` 約 60 個（訓練 ~40、熱身 8、伸展 10、休息頁 3）。動作庫 99 個動作會對應到這些示範。
  2D 版的角度資料在 `scripts/art/moves.js`，可當作 3D 的參考（側面角度 → 3D 要補左右寬度、手腳釘點）。
- 裝備：12 系列 × 8 部位 ＝ 96 件（`GearCatalog.swift`）。CLAUDE.md 的美術規定照樣適用（灰階認得出、同部位不撞形、越稀有越華麗）。
  目前只有鈦甲（titan）做了 3D 測試版，可逐部位混搭（`GEAR="head=titan,hands=titan"`）。

## 防穿模（動作多、造型多，小穿模可接受，但要系統化排除）
三層做法，越前面越省事：

**1. 設計規則（做裝備時就避開）**
- 硬殼裝備（盔甲片、護膝、手甲）只綁一根骨頭，放在肢段中段，**不跨關節**；關節附近只放小而圓的零件。
- 往身體外側凸的零件（側板、肩甲）有寬度上限：大腿側板離大腿中心線 ≤ 7 cm（手拿啞鈴會碰到）。
- 軟的衣服（背心、短褲、緊身衣）沿用身體權重（Data Transfer）；衣服底下的身體往內壓 1.2 cm，完全蓋住的身體面刪掉。
  衣服只比身體大約 5%：再大會變形（背心放大到 12% 時胸口鼓成球、腰被收成沙漏）。
- 沒有袖子的衣服不吃手臂權重；身體軀幹（|x|<0.235）的手臂權重改給胸部。

**2. 動作層（做動作時就處理）**
- 接地修正：每一格算整個角色最低點，有東西沉到地板下就把整個人抬高（裝備比基本款厚時自動生效）。
- 背靠椅背或躺在椅子上的動作，示範時**隱藏背部裝備**（披風、背包），`hero_proto.py` 的清單。
- 手拿啞鈴的動作，手的軌跡要繞開大腿（深蹲蹲低時手往外）。

**3. 自動檢查（`scripts/blender/clipcheck.py`，每個動作 × 每個系列都跑）**
- 逐格（每 2 格）用三角形相交檢查：裝備 × 其他骨頭、身體 × 不相鄰骨頭、角色 × 器材（硬器材／軟墊分開）、沉入地板。
- 關節相連的骨頭本來就會重疊，不算；碰到軟墊（座墊、滾筒）是正常接觸，只列出不計入最嚴重的格。
- 只把最嚴重的格截圖給人看，不用逐格目視。修不掉的小穿模記在報告裡，可以接受。
- 動作 60 個 × 系列 12 個＝ 720 組，全部是電腦跑，不花 token；只有有問題的組才需要我看圖修。

## 階段
1. **技術驗證（先做，決定整條管線）**：把基本款角色＋一個動作放進 App，用 RealityKit 即時播放，上機確認：
   - 格式：USDZ（帶骨架動畫）。這裡的 Ubuntu Blender 4.0 沒有 USD 匯出；改在 GitHub Actions macOS runner 下載官方 Blender 匯出，
     或在這裡用 Python 3.11 + PyPI `bpy`。
   - 卡通著色：RealityKit `CustomMaterial`（Metal surface shader）做兩階明暗＋邊緣光。
   - 描邊：模型裡烘一層反向外殼（solidify），用 UnlitMaterial、剔除正面。
   - 裝備開關：每件裝備是獨立節點，依背包啟用／隱藏；動作片段（clip）切換。
   - 效能、IPA 大小、「減少動態效果」時的處理（停在關鍵姿勢）。
2. **動作全部做完**：依器材分批，每批出一張總覽圖給使用者看：
   站姿啞鈴（肩推、彎舉、側平舉、划船、硬舉…）→ 椅子（臥推、上斜、仰臥…，用 `build_bench` 調靠背角度）→
   滑輪（下拉、三頭下壓、面拉、划船…）→ 地板徒手（伏地挺身、棒式、臀橋…）→ 熱身 → 伸展。
3. **裝備全部做完**：一次 2～3 個系列，每系列一張 8 部位總覽＋混搭圖。
4. **角色頁改成 3D**：舞台、換裝、開箱、套裝效果、特效。2D Canvas 版（`CharacterCanvas`、`GearArt`）確定不用後再移除。

## 省用量的做法
- 一次做多個（動作一批 5～8 個、裝備一次 2～3 系列），每批只出一張低解析度總覽圖。
- 有範本之後（鈦甲、伏地挺身、下拉），照範本量產可以考慮用 Sonnet；新系列的造型方向和最後檢查用 Opus。
