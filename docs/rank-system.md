# 牌位系統（交接文件）

## 規則（`Workout/Rank/Rank.swift`）
- 分數完全由 `WorkoutSession` 即時算出，不另外存；刪紀錄、改每週目標都會重算。
- 加分：完整 +20、精簡 +12、只做 1 組 +5；破個人紀錄每個動作 +5（單次最多 +15，定義同進步頁：負重動作重量超過以前最高，第一次不算）。
- 每週結算（本週不算）：達到每週目標 +15，連續達標每週再 +5（最多 +20）；只練 1 次 −20；整週沒練 −50。分數不低於 0。
- 牌位：鐵牌 / 銅牌 / 銀牌 / 金牌 / 白金 / 鑽石（各 III→II→I，每段 50/75/110/160/240/360 分，約每階 ×1.5）→ 大師（2985 起，寬 2000）→ 王者（4985 起）。
  進入分數：銅 150、銀 375、金 705、白金 1185、鑽石 1905。
- **越高越難（0.40.0 起，`RankEngine.applyTierRules`）**：ledger 排序後依序走一遍，所以前綴加總（結算畫面的 before/after）仍然一致。
  - 扣分倍率（看扣分當下的牌位）：鐵～銀 ×1、金／白金 ×1.5、鑽石 ×2、大師以上 ×3。整週沒練在大師扣 150。
  - 晉級條件（`RankEngine.gates`）：白金＝連續達標 2 週；鑽石＝4 週＋完整訓練天數 ≥ 這幾週目標的 50%；
    大師＝6 週＋75%；王者＝8 週＋100%。完整訓練只算目前連續達標裡最近那幾週（請假、保護卡的週跳過，不中斷）。
    條件看「到這筆為止已結算的週」，週結算那筆本身也算進去。沒達成就只入帳到上一階的最後 1 分，多的不存（事件 reason 會註明原本幾分）。
    掉出去再回來要重新檢查。
  - 一週練滿 4 次約 +115～145 分（含週任務）：約 5 週金牌、3～4 個月鑽石、大師約 5 個月，王者約 9 個月到一年（還要過 8 週全完整的條件）。
  - 規則改版時 `RankEngine.rulesVersion` 加 1：今天頁直接記下重算後的牌位，不播掉段動畫。
  - 畫面：牌位小卡在下一階有條件時寫「再 N 分＋晉級條件」，卡住時改寫條件進度；詳情頁 hero 下方有條件進度框，規則區列出倍率和所有條件，牌位一覽每階寫條件。
  - 練完的成果畫面加分：取「舊公式」和「ledger 前後差」的較小值，卡住時顯示 +0。

## 畫面
- 中央圖案（0.8.0 起）：彎手臂秀二頭肌＋正面握拳，牌位越高肌肉越大（`muscleArm(t)`，t = 0 鐵 → 7 王者）。
  手臂整體大小、上臂粗細、二頭肌隆起、前臂粗細都隨 t 變；拳頭只略微變大（鐵 0.47 → 王者 0.59）。
  銀起有光澤、金起有力量線（在拳頭右側，不可放在手指正上方）、白金起有青筋、大師起有肌肉分線。
  拇指只壓到食指和中指，不可越過無名指。舊的器材圖示仍在 `emblem()`，`BADGE_EMBLEM=tool` 可預覽。
- 獎章每階外框都不同：鐵＝八角鐵板＋鉚釘＋啞鈴、銅＝齒輪圓章＋月桂＋緞帶尾＋壺鈴、銀＝盾＋交叉雙劍＋槓鈴、
  金＝太陽光芒圓牌＋翅膀＋星、白金＝六角水晶＋碎晶翼、鑽石＝菱形水晶＋羽翼＋頂端水晶、大師＝星徽＋大翼＋皇冠＋光環、
  王者＝火焰盾＋巨翼＋寶石皇冠＋光芒＋獎盃。同一階的三個小段外形差很多（`tierLayers(ti, lv)`，lv 0＝III、1＝II、2＝I）：
  III 是樸素的核心徽章（整體縮到 0.86 倍），II 加上該階的招牌配件（0.94 倍），I 配件加大加多，背後有光暈和四顆星光。
  鐵＝III 素面、II 鉚釘＋夾板、I 雙層夾板＋鐵刺；銅＝III 只有齒輪、II 半圈月桂＋緞帶尾、I 整圈月桂＋雙層緞帶尾＋星；
  銀＝III 只有盾、II 雙劍、I 矛尖＋金邊金鉚釘；金＝光芒 8→12→16 道，II 小翼、I 大翼＋星；
  白金＝III 沒有翼、II 碎晶翼 2 片、I 3 片＋頂端水晶；鑽石＝III 沒有翼、1 根刺，II 羽翼 4＋3 根刺，I 羽翼 6＋5 根刺。
  牌位一覽（沒指定小段）畫 I 的樣子。
- 小段是底部緞帶上的羅馬數字 III／II／I（畫成有襯線的路徑，不靠字型；0.7.1 起，之前是 1～3 個 ^）。不使用任何遊戲的原圖。
- 形狀資料：`node scripts/art/badges.js [預覽.html]` 產生 `Workout/Rank/RankBadgeArt.swift`（不要手改），
  `RankBadge` 用 Canvas 依資料畫。
- 今天頁（主卡下方）、進步頁（標題下方）有牌位小卡，點進去看規則、所有牌位、最近分數變化。
- 晉級／掉段：`TodayView.checkRank()` 比對 `lastRankIndex`（UserDefaults），變了就跳 `RankChangeView`。第一次只記錄不跳。

## 動畫（0.9.0 起）
- **一份資料、兩個渲染器**：`scripts/art/badges.js` 幫每個圖層標上部位（`PART`：翼、齒輪、月桂、緞帶尾、刺、皇冠、火舌、
  手臂、力量線、星光…）、支點、第幾片、是否鏡像、是否為輪廓，並輸出每階的動作表 `MOTION`、粒子表 `PARTICLES`、反光 `SHEEN`。
  App 用 `Workout/Rank/BadgeMotion.swift`（`BadgeRenderer`），預覽用 `scripts/art/badge-anim.js`，兩邊公式一一對應，改一邊要改另一邊。
- **預覽**：`node scripts/art/badges.js 預覽.html`，用瀏覽器打開就會動；上半是 22 枚待機動畫，下半是晉級場景（按鈕切換）。
  網址加 `?t=1.2` 固定待機時間、`?demo=1&st=2.5&t=0` 固定場景與時間，方便截圖。
- **待機動作**（`RankBadge(motion: .live)`，詳情頁和預覽）：每階都會「秀肌肉」（每 3.4 秒用力一次，力量線同步閃）。
  鐵＝用力時鐵板震、鐵刺彈＋火花；銅＝齒輪轉、月桂擺、緞帶飄＋金粉；銀＝用力時雙劍交擊＋閃光；金＝光芒轉、翅膀拍＋繞圈光點；
  白金＝碎晶浮動＋繞圈小水晶；鑽石＝羽翼一片片拍＋星光、亮粉落下；大師＝羽翼、皇冠浮動＋螺旋上升紫光；王者＝火舌跳動、巨翼、光芒反轉＋火星。
  每階都有反光掃過輪廓。
- **粒子分級**（0.10.0 起，牌位越高越酷，見 `badges.js` 的 `PARTICLES`）：鐵＝火花＋用力迸鐵屑；銅＝金粉＋零星閃光；
  銀＝雙劍交擊時白色噴發＋擴散波；金＝背後光柱＋2 道拖尾彗星；白金＝旋轉符文環＋斜軌彗星＋水晶；
  鑽石＝雙層符文環＋4 道彗星＋鏡頭光芒＋亮粉；大師＝紫色閃電＋5 道彗星＋螺旋紫光＋雙層擴散波；
  王者＝往上竄的火舌＋滿天火星＋火焰符文環＋6 道火彗星＋金色閃電＋雙鏡頭光芒＋最大的噴發。
  噴發與擴散波跟手臂用力同步。羅馬數字緞帶畫在粒子上面。`.live` 的畫布比獎章大 30%，讓外圈粒子不被切掉。小卡用 `.shine`（出現時掃一次），列表用 `.still`。開啟「減少動態效果」全部變靜態。
- **晉級場景**（`RankScene.swift`，全部是時間 t 的函式，點畫面跳到結尾）：
  升小段＝蓄力震動變白 → 白光 → 新配件飛入、羅馬數字翻牌 → 彩帶；
  跨階＝蓄力（光點往中心收、越震越快）→ 白光＋衝擊波、舊獎章碎片炸開 → 光柱＋旋轉光芒、新獎章由底座→手臂→配件→皇冠依序組裝 → 落地衝擊＋彩帶；
  大師多紫色漩渦、皇冠從畫面頂端落下；王者多滿畫面火星與紅色背景；掉段＝配件一片片掉落、變灰 → 新獎章安靜淡入。觸覺節奏見 `RankScene.haptics`。
- **今天頁的順序**：每週結算（`WeeklySettlementView`，週一第一次打開）→ 分數入帳（`RankCard` 數字跑動、加分標籤、跨段時獎章彈一下）→ 晉級場景。
  練完時等訓練畫面收起（`fullScreenCover` 的 `onDismiss`）才開始播。記錄在 `lastRankPoints`、`lastRankCheck`、`lastSettledWeek`。
- **進度條**：一直有光掃過；90% 以上整條發光脈動。牌位一覽由下往上滑入，點任一階開 `RankPreviewSheet`（未達成＝解鎖預告）。
- 其他畫面共用 `Workout/Art/FX.swift`（光芒、衝擊波、彩帶、聚氣、火星、漩渦、灰塵、噴發）與 `HapticScript`：
  破紀錄 `PRBurstView`、完成訓練 `WorkoutCompleteView`、休息倒數 `RestCard`、開箱、換裝備 `EquipFlash`（`Workout/WorkoutFX.swift`）。
