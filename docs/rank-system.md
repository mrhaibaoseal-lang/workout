# 牌位系統（交接文件）

## 規則（`Workout/Rank/Rank.swift`）
- 分數完全由 `WorkoutSession` 即時算出，不另外存；刪紀錄、改每週目標都會重算。
- 加分：完整 +20、精簡 +12、只做 1 組 +5；破個人紀錄每個動作 +5（單次最多 +15，定義同進步頁：負重動作重量超過以前最高，第一次不算）。
- 每週結算（本週不算）：達到每週目標 +15，連續達標每週再 +5（最多 +20）；只練 1 次 −20；整週沒練 −50。分數不低於 0。
- 牌位：鐵牌 / 銅牌 / 銀牌 / 金牌 / 白金 / 鑽石（各 III→II→I，每段 50/75/100/125/150/200 分）→ 大師（2100 起）→ 王者（3000 起）。
  一週練滿 4 次大約 +115 分：約 6 週金牌、13 週鑽石、半年王者。

## 畫面
- 獎章每階外框都不同：鐵＝八角鐵板＋鉚釘＋啞鈴、銅＝齒輪圓章＋月桂＋緞帶尾＋壺鈴、銀＝盾＋交叉雙劍＋槓鈴、
  金＝太陽光芒圓牌＋翅膀＋星、白金＝六角水晶＋碎晶翼、鑽石＝菱形水晶＋羽翼＋頂端水晶、大師＝星徽＋大翼＋皇冠＋光環、
  王者＝火焰盾＋巨翼＋寶石皇冠＋光芒＋獎盃。同一階的三個小段外框也不同，越高越華麗（`tierLayers(ti, lv)`，lv 0＝III、1＝II、2＝I）：
  鐵＝II 加兩側鐵夾板、I 再加頂端鐵刺；銅＝月桂 3→5→6 片、I 頂端加星；銀＝II 盾頂加矛尖、I 劍尖加星光；
  金＝III 沒有翅膀、II 小翼、I 大翼＋頂端星；白金＝碎晶翼 1→2→3 片、I 頂端加水晶；鑽石＝羽翼 2→4→5 片、水晶刺 1→3、I 加星光。
  牌位一覽（沒指定小段）畫 I 的樣子。
- 小段是底部緞帶上的羅馬數字 III／II／I（畫成有襯線的路徑，不靠字型；0.7.1 起，之前是 1～3 個 ^）。不使用任何遊戲的原圖。
- 形狀資料：`node scripts/art/badges.js [預覽.html]` 產生 `Workout/Rank/RankBadgeArt.swift`（不要手改），
  `RankBadge` 用 Canvas 依資料畫。
