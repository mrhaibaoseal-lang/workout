# 練壯（Workout）

在家用現有器材練壯的 iPhone App（SwiftUI + SwiftData，iOS 17 以上）。

## 功能

- **每週 4 天新手增肌課表**：上半身 A（胸背）/ 下半身 A（大腿前側）/ 上半身 B（肩背手臂）/ 下半身 B（臀、大腿後側），依序輪流。每個肌群一週練 2 次、約 9–12 個正式組。中斷了不用重來，只要接著練下一天。
- **在家／健身房模式**：在家用設定裡勾的器材；健身房模式什麼都有，還可以「換動作」（器材被佔用時換成練同一部位的）。
- **熱身組**：依正式組重量自動算（例如 50% × 10、75% × 5），每個部位第一個動作才做完整熱身。
- **遞增組／遞減組／Drop set**：每個動作可選固定、遞增（金字塔）、遞減（倒金字塔）、最後一組 Drop set，或交給「自動」。選過會記住。
- **還剩幾下（RIR）**：每組可以點「還剩幾下力氣」，還剩 4 下以上自動幫後面的組加重，力竭又沒做到就減重。
- **身體數據**：體重、體脂、各部位圍度。不用拍照，用依圍度畫出來的身形圖（疊上第一次的虛線輪廓）和曲線看變化，還有肩腰比、BMI。
- **三種長度**：完整版（約 60 分鐘）、精簡版（約 20 分鐘，只做最重要的 3 個動作）、只做 1 組（最懶的日子，做完會問要不要再多做一點）。
- **自動排程**：讀課表（可從截圖辨識）和「打工薪水帳」的班表，扣掉上課、打工、通勤，自動排出每週哪幾天練、練完整或精簡、幾點開始。
- **練習提醒**：照排出來的時間提醒；當天已經練過就不會提醒。
- **絕不連續兩次**：上次排定的練習日沒練，首頁會跳出提醒，一鍵開始「只做 1 組」。
- **主畫面／鎖定畫面小工具**：顯示本週練了幾次、連續幾週、下次練什麼。
- **依器材自動挑動作**：在設定勾選器材，課表會換成你做得到的動作。
- **自動加重建議**：上次全部組都做到次數上限就建議加重，沒做到就建議多做 1 下。
- **週期安排**：第 1-2 週是適應期（練輕一點），每 6 週有一次減量週，之後換一批動作。
- **進步曲線**：每個動作的估算最大力量或次數走勢，加上每週訓練次數。
- **角色與裝備**：「角色」分頁有一個依訓練動作（深蹲、肩推、硬舉）即時繪製的角色。每完成一次訓練得 1 個補給箱，開箱抽 12 個系列的裝備（普通／稀有／史詩／傳說，含保底、套裝效果、重複轉碎片可兌換）；黃金系列要靠里程碑（訓練次數、連續週數、破個人紀錄）取得。
- **請假與公平的懲罰**：今天或昨天可以請假，不算漏練；每請 2 天週目標少 1 次，請假 4 天以上那週不結算。排程本來就排不出時間的週不扣分。
- **保護卡**：練滿一週得 1 張（最多 2 張，也能用碎片買），沒達標的週自動抵銷，連續週數不中斷。
- **週任務與押注**：每週 3 個任務（每項 +10 牌位分，全破再送 1 個補給箱）；可以押碎片賭自己會練滿這週。漏練後馬上練回來有「逆轉」加分。
- **影子對手、總重量里程碑**：進步頁比較最近 28 天和前 28 天的自己，累積舉起的重量從機車一路到艾菲爾鐵塔。
- **狀態與屬性**：角色頁顯示狀態（太久沒練會變差）和力量、下盤、耐力、韌性四項屬性，屬性會加到戰力。規則見 [`docs/goals-system.md`](docs/goals-system.md)。
- **休息計時器**：每打勾一組就開始倒數。
- 資料只存在手機上，不需要帳號。
- **重裝不用重設**：設定（器材、重量上限、課表、行程、提醒等）會備份到 Keychain，刪掉 App 再裝回來會自動還原（需同一張憑證、同一個 Bundle ID）。訓練紀錄不在備份內。

## 雲端編譯與安裝

每次 push 都會觸發 GitHub Actions（`.github/workflows/build.yml`）：

1. 在 macOS 機器上用 XcodeGen 從 `project.yml` 產生專案，編出**未簽名**的 `Workout.ipa`。
2. build 號自動使用 Actions 的執行編號，每次都會遞增，Feather 才會顯示「有更新」。
3. 透過 [`mrhaibaoseal-lang/feather-source`](https://github.com/mrhaibaoseal-lang/feather-source) 的 action 發佈成 GitHub Release，私人 Feather 來源會自動收錄。

安裝：在 Feather 重新整理私人來源 → 下載「練壯」→ 用 FlareStore 憑證簽名安裝。

## 專案結構

```
project.yml                 XcodeGen 專案設定
Workout/
  WorkoutApp.swift          App 進入點、分頁
  Models.swift              SwiftData 資料模型、器材
  ExerciseLibrary.swift     動作庫
  Program.swift             課表、週期、加重建議、統計
  TodayView.swift           今天練什麼
  Session/                  訓練中畫面：WorkoutView（主畫面）、ExerciseCard、SetRows（組的列與編輯）、RestCard、WorkoutDrafts
  Reminders.swift           練習提醒通知
  Schedule/                 課表、班表讀取、自動排程、課表截圖辨識
  ProgressScreen.swift      進步圖表（右上角可開訓練紀錄）
  HistoryView.swift         訓練紀錄
  Character/                角色與裝備：骨架動作、裝備目錄、Canvas 繪製、背包、角色分頁、開箱、碎片兌換
  Settings/                 設定主頁與五個分頁（器材、訓練、課表與動作、排程與提醒、資料）、第一次開啟引導、Keychain 備份
Shared/SharedStore.swift    App 與小工具共用的資料（App Group）
WorkoutWidget/              主畫面小工具
```
